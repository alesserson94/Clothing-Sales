# Clothing-Sales

**Introduction**

This is a project using a synthetic dataset (generated by AI) for clothing sales across various clothing stores (i.e. Old Navy, GAP, Banana Republic, etc). The goal is to identify patterns/trends in sales across various store brands and product types.

**Questions to Answer:**
1. Find the total revenue per store
2. Which product(s) drive the most revenue/number of transactions? Is there a correlation?
3. Identify revenue trends over 2023 & 2024
4. Which sales rep generated the most revenue?
5. Which brands have higher/lower discounts on average?

**Tech Stack/Tools Used**
1. MySQL (Joins, CASE statements)
2. Excel
3. Tableau
